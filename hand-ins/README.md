# Hand-ins (collected here, never given to coders)

Each finished hand-in, `facets-r2-<coder>-<YYYYMMDD>/`, arrives here only after its coder is done. On Explorer this folder is a drop box. Coders make their own folder here with `mkdir` and copy their files in with `cp -R`. Nobody can list the drop box, and each folder made here is closed to everyone except its coder and Bear. Hand-ins sent to Bear are copied in by him. `scripts/make_agent_copy.sh` leaves this folder out of every coder's copy. Compare only once every coder has handed in (README.md, "Compare"). The hand-ins quote posting text, so they stay private.
