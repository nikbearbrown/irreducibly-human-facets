# Hand-ins (collected here, never given to coders)

Each finished hand-in, `facets-r2-<coder>-<YYYYMMDD>/`, arrives here only after its coder is done. On Explorer, coders copy their own folder in; this folder is a drop box they can write to but not list or read. Hand-ins sent to Bear are copied in by him. `scripts/make_agent_copy.sh` leaves this folder out of every coder's copy. Compare only once every coder has handed in (README.md, "Compare"). The hand-ins quote posting text, so they stay private.
